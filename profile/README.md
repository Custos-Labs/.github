# Custos Labs

**Open-source infrastructure for authentication, authorization, identity, and governance.**

Custos is production-minded backend infrastructure that doubles as a complete educational resource for learning backend engineering, software architecture, and security.

## What we build

- **Credentials and sessions** — Authentication and session handling designed as independently testable modules.
- **RBAC and authorization** — Role-based access control with clear boundaries between policy and enforcement.
- **Audit logging and governance** — Every subsystem (credentials, sessions, RBAC, audit) is reusable on its own under packages/.
